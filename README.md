Let's you send text messages using Clash Royale troop placements!

* Download and setup BlueStacks using [this](https://github.com/Pbatch/ClashRoyaleBuildABot/wiki/Emulator-Setup-Guide) tutorial.
* Setup the python project and install libraries from requirements.txt.
* Run app.py in the frontend folder, open in a browser.
* Run bot.py in the main folder, it should connect to BlueStacks using adb. Player 1 initilises matches, player 2 accepts them.
